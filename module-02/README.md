# Модуль 2: Введение в операторы

## Обзор

Теперь, когда вы понимаете архитектуру Kubernetes, паттерн контроллера и пользовательские ресурсы (Custom Resources) (из [Модуля 1](../module-01/README.md)), пришло время создать свой первый оператор! Этот модуль знакомит с паттерном оператора и учит использовать Kubebuilder для создания операторов, управляющих пользовательскими ресурсами.

**Продолжительность:** 5–6 часов  
**Предварительные требования:** 
- Завершение [Модуля 1: Глубокое погружение в архитектуру Kubernetes](../module-01/README.md)
- Базовые знания Kubernetes
- Основы программирования на Go

## Цели обучения

К концу этого модуля вы:

- Поймёте паттерн оператора и когда его использовать
- Узнаете, как работает Kubebuilder и его архитектуру
- Настроите полноценную среду разработки
- Создадите и запустите свой первый оператор «Hello World»
- Разберётесь в структуре проекта оператора

## Проверка предварительных требований

Перед началом убедитесь, что вы завершили Модуль 1:

- ✅ Понимаете компоненты управляющего слоя Kubernetes
- ✅ Знаете, как работают механизмы API
- ✅ Понимаете паттерн контроллера и согласование
- ✅ Умеете создавать и использовать пользовательские ресурсы (CRD)

Если вы не завершили Модуль 1, начните с [Модуля 1: Глубокое погружение в архитектуру Kubernetes](../module-01/README.md).

## Настройка

Перед началом этого модуля:

1. **Проверьте завершение Модуля 1:**
   - Вы должны понимать CRD из [Урока 1.4](../module-01/lessons/04-custom-resources.md)
   - Вы должны понимать контроллеры из [Урока 1.3](../module-01/lessons/03-controller-pattern.md)

2. **Убедитесь, что среда разработки готова:**
   ```bash
   ./scripts/setup-dev-environment.sh
   ```

3. **Запущенный кластер kind:**
   ```bash
   ./scripts/setup-kind-cluster.sh
   ```

4. **Проверьте, что kubebuilder установлен:**
   ```bash
   kubebuilder version
   ```
